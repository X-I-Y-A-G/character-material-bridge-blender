# Character Material Bridge 0.5.26 / 角色材质桥 — 开发版

**普通使用者请下载 [User 用户版](https://github.com/X-I-Y-A-G/character-material-bridge-blender/releases/download/v0.5.26/character_material_bridge_user-0.5.26.zip)。** 本开发版供需要制作、导出源材质包或最终材质包的作者使用。

## 安装与版本要求

必须在 **Blender 5.2 及以上版本（5.2+）** 安装、使用和验证。已有完整运行验收环境为 Windows / Blender 5.2.2 LTS；其他版本需在实际环境验证。

从 Blender 偏好设置安装 `character_material_bridge-0.5.26.zip`，启用 **Character Material Bridge / 角色材质桥**。开发版与用户版只能启用其中一版；升级后建议重启 Blender。入口为 3D 视图 → N 侧栏 →「材质移植」。

## 从源工程制作材质包

1. 在源工程的物体模式下，只选择需要分享的角色网格。
2. 点击「导出所选角色材质包」，使用新的 `.blend` 文件名，避免覆盖源工程或已有材质包。
3. 包中保存材质、节点、打包图像和受支持的修改器，并记录匹配信息；源骨架修改器不导出。
4. 当前源包默认包含清理后的 UV 参考网格，用于接收端复制源 UV。它包含基础几何与 UV，移除骨架、权重、形态键、动画和无关属性；不是“全部零顶点”的包。
5. 将材质包交给同角色 MMD 模型的使用者。接收端可用 User 用户版完成移植。

非白名单修改器、脚本节点、Geometry Bake 缓存及不受支持的图像类型会明确拒绝导出。对象或集合引用保存为占位，目标工程需提供同名且类型一致的依赖。

## 移植与确认

选择目标角色网格 → 选择材质包 → 分析匹配 → 核对或载入映射预设 →「复制角色、按材质分离并移植」。无需预先手工分离。

匹配综合贴图、材质名和 UV 证据；共享贴图或同名多源组合可能保留歧义。人工确认后用 `.mapping.json` 保存对应关系，不应仅凭最高分强制选择。

插件处理副本并隐藏保留原角色。失败时回滚本次操作；跳过区域保留原材质。查看 `CMB_Report.json`，并检查结果实际外观及动画。

## 调整结果并导出最终包

- 可调节材质参数、参数动画、推荐默认值、描边宽度和后处理；参数预设用于保存调节值。
- 切线修复使用目标 UV 与法线及源端校准约定；描边平滑使用目标自身数据。修改目标 UV 或法线后，应核对并按需重新修复。
- 独立灯光、相机描边、头骨基座及参数动画同步由插件提供，不要求 Importer。「实时预览同步」可以暂停预览，正式渲染仍同步当帧数据。
- 选择最终移植结果，执行最终材质包导出。默认可包含校正参考网格，保留表面法线、切线、UV、顶点色和描边数据；可关闭参考网格以导出纯材质模式。
- 最终包自动生成同名配套 `.blend.mapping.json`。两个文件应一同分发；接收端分析匹配后载入配套预设再应用。
- 校正恢复要求目标基础位置和拓扑顺序一致。最终包依赖的目标对象、骨架或集合须同名存在；不应通过携带完整源工程解决缺失引用。

## 数据与运行边界

`.blend` 是开放格式，材质、节点和图像可被手工追加。当前源包及可选最终包会包含用于 UV 或着色校正的清理参考网格；骨架、权重、形态键、动作、场景、世界和原工程文本不随角色包导出。

保留目标骨架、顶点组和形态键，不代表已完整验证 MMD 材质 morph、物理引用和全部动态组合。复杂工程应备份并验证实际运行及视觉表现。

内置后处理会检查 OCIO 兼容性；不兼容时保留用户合成与色彩管理。0.5.26 已加固 GUI 动画渲染同步，渲染期间会锁定界面。5.3 Alpha 原始崩溃尚未复现，其他版本和插件组合需按实际工程验证。
