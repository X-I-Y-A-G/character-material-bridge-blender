# Character Material Bridge 0.6.1 / 角色材质桥 — User 用户版

**普通使用者请选择 `character_material_bridge_user-0.6.1.zip`。** 用户版用于接收、应用别人提供的材质包，支持调参、参数动画和独立运行同步。需要制作、导出源材质包或最终材质包的作者，使用开发版。

本分支尚未发布 GitHub Release；安装构建产物 `character_material_bridge_user-0.6.1.zip`。

## 安装与版本要求

- 必须在 **Blender 5.3 及以上版本（5.3+）** 安装、使用和验证。
- 本分支实测环境为 Windows / Blender 5.3.0 Beta（3e084785de9a）。其他版本需在实际环境验证；不把此要求视为所有后续版本都已经实测。
- 从 Blender 偏好设置中选择“从磁盘安装”，安装上述 User ZIP，启用用户版条目。入口为 3D 视图 → N 侧栏 →「材质移植」。
- 开发版与用户版只能启用其中一版。升级后建议重启 Blender，释放旧模块和回调。
- GitHub 自动提供的 Source code 压缩包是源码仓库；安装时请选择 User 安装包。

## 应用材质包

1. 在目标工程中准备同角色的 MMD 模型，并向材质包作者取得 `.blend` 材质包。如有配套 `.mapping.json`，放在材质包旁。
2. 切到物体模式，选中要移植的角色网格，点击「选择材质包」。无需预先按材质手工分离。
3. 点击「分析所选角色 / 刷新匹配」。检查每个区域对应的源材质和修改器组合；自动选择后仍应核对结果，无法确认的区域可保持跳过。
4. 如有配套映射预设，点击「载入预设」。人工确认后的对应关系可用「保存预设」保存，方便下次复用。
5. 点击「复制角色、按材质分离并移植」。插件处理副本并隐藏保留原角色；跳过的区域继续使用原材质。
6. 查看 `CMB_Report.json` 中的应用、跳过及警告信息。更改对象选择、材质槽或材质包后，应重新分析。

最终包可能依赖同名目标对象、骨架或集合。缺少引用时会列出缺失名单并中止，请向包作者确认目标模型及命名要求。参考网格恢复还需要目标基础位置与拓扑顺序一致；不一致时可关闭「恢复最终包网格校正数据」，再按目标数据重建。

## 调参与动画

- 「参数调节」面板提供部位和材质选择、搜索、界面分组、已修改筛选及默认值恢复；四分量颜色包含独立 Alpha。
- 参数控件上可按 I 或右键插入关键帧，支持关键帧、驱动及 NLA。动画保存在当前 Blender 工程中，需要保持插件启用。
- 参数预设用于保存调节值。恢复默认或载入预设不会删除原有动画曲线。
- 「调整描边宽度」支持当前部位或所选移植部位，以倍率或指定数值调整。

## 灯光、相机与实时同步

- 独立同步随插件提供，不要求安装 Importer。旧结果需要时可使用「初始化／修复独立同步」。
- 设置场景活动透视相机，并添加 Sun 日光；独立同步面板可指定主日光及头骨绑定。
- 「实时预览同步」默认开启。关闭时冻结材质桥的自动预览，手动调参仍立即生效；「立即同步当前帧」可主动刷新。
- 正式渲染和保存会同步当帧数据，不改变预览开关。渲染期间工程界面会被锁定，完成或取消后由 Blender 解除锁定。
- 当前描边使用透视公式，正交或全景相机需自行验证表现。

## UV、毛绒与后处理

- 新源包可携带源 UV 参考网格。「移植源 UV 数据」默认开启；同名但不同的层另存为 `CMB_Source_原层名`，无法可靠匹配或超过容量时跳过并记录，不覆盖现有层。
- 最终包可携带校正参考网格，用于恢复法线、切线、UV、顶点色和描边数据，保留目标骨架、权重及形态键。
- 支持识别已有多层毛绒或按源配方生成外壳；请按作者说明映射底层和毛绒外层条目。
- 首次移植会尝试接入内置后处理并备份原设置。重复移植保留现有调节；不兼容的 OCIO 配置会跳过内置后处理，保留用户合成与色彩管理。

## 恢复与问题反馈

选中同批移植结果，点击「移除所选移植结果并恢复原角色」，可删除该批生成部件并恢复原角色。生成部件上的后续编辑也会被删除；需要保留时请先备份工程。支持 Blender 原生撤销。

反馈问题时提供 Blender 版本、插件版本、材质包来源、异常部位和 `CMB_Report.json` 相关信息。MMD 材质 morph、外部物理引用和复杂动画组合尚需按工程验证；结构检查不等于最终视觉一致。

0.6.0 的主要修复为 GUI 动画／视频渲染逐帧同步。已清理渲染工作线程中的界面上下文覆盖、递归依赖图更新和 GPU 释放路径；用户反馈的 5.3 Alpha 原始崩溃尚未复现，不承诺所有 Alpha 构建及插件组合都已验证。
## Blender 5.3 实时同步

新式 Ruri 材质使用数值组输入批量传递参数，原生灯光图跟随 EEVEE 场景灯光；旧参数图材质继续使用兼容路径。相机投影在同一轮同步中共用计算。在「独立运行同步」中，「启用世界环境控制」默认开启，已接入的角色环境光跟随 World 的 Background / HDRI / Mapping；复杂 World 图会提示并保留上次有效值。关闭开关后显示「环境颜色」（RGB）和「环境强度」，独立控制角色环境光，保留场景背景。两项支持关键帧；强度为 0 时关闭该环境光。切回 World 后仍保留独立设置，开关及设置随当前工程保存。性能与适配边界见仓库 `docs/blender53.md`。

普通用户选择 User 版；安装后保存工程并完整重启 Blender。参数动画仍需保持插件启用，历史材质包不会自动重写成新着色算法。
